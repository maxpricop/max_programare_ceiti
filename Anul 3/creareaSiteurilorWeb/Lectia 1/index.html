Lucrare practică nr. 1

Structura unui document HTML și formatarea textului.

Realizat de Maxim Pricop.

Exerciții

  1. Magazin: titluri și text preformatat
  2. Teoreme de congruență a triunghiurilor
  3. Formule: indici și exponenți
  4. Modele din imagine:
    • Linii aliniate la dreapta
    • Linii centrate
    • Text în trepte
  5. Poezie: culoare și stilul textului

Extinderea este inclusă: secțiuni marcate prin comentarii HTML și structură completă în fiecare fișier.
